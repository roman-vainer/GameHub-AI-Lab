# Agent Instructions



## Project purpose



GameHub is an educational project used to practice AI-assisted software development.



The main goal is not only to build the application, but also to learn how AI coding agents work with requirements, repositories, issues, tests, code review and pull requests.



## Working rules



Before changing code:



1\. Read the relevant requirements in docs/requirements.md.

2\. Inspect the existing project structure and code.

3\. Do not modify unrelated files.

4\. Preserve existing working behavior unless the task explicitly requires a change.

5\. Do not add external packages unless they are necessary.

6\. Prefer simple and readable solutions.

7\. Do not implement features that were not requested.

8\. Run the project and tests after making changes when possible.



## Communication



When completing a task, explain:



\- what was changed

\- why it was changed

\- which files were modified

\- whether tests or validation were performed
